# Soner Berşe web sitesi

Bu projede içerik veya yayın üzerinde çalışmadan önce `YAZILARIM.md` dosyasını okuyun. Kullanıcı aynı kayıtlı projede asistanla yazı hazırlayıp önizlemek ve yayımlamak ister.

Mevcut kullanıcı değişikliklerini koruyun. `dist/` ve `.preview/` üretilen çıktılardır; asıl kaynakları düzenleyin. Kullanıcının mevcut `public/` klasörü çıktı değildir, temizlemeyin.

Depo herkese açıktır. Onaylanmamış yazıları yalnızca sürüm takibi dışındaki `content/drafts/` içinde tutun; kullanıcı adına örnek yazı veya görüş uydurmayın. `main` dalına gönderim canlı Vercel yayınını tetikler; oturumda verilen yayın yetkisine göre hareket edin.
